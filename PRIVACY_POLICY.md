# Privacy Policy — Classic Subtitles

**Last updated:** March 10, 2026

## Overview

Classic Subtitles is a browser extension that displays translated subtitles on web pages to help users learn languages. We are committed to protecting your privacy.

## Data Collection

Classic Subtitles does **not** collect, store, or transmit any personal information.

## What the Extension Accesses

- **Website text content:** The extension reads visible text on web pages you visit in order to generate translated subtitles. This text is sent to the Google Translate API (`translate.googleapis.com`) solely for the purpose of translation. No text is stored on any server we control.

- **User preferences:** Your settings (language choice, font size, display options) are saved locally in your browser using Chrome's built-in `chrome.storage.sync` API. These settings sync across your Chrome browsers if you are signed in to Chrome, as part of Chrome's native sync functionality.

## Third-Party Services

The extension sends page text to the **Google Translate API** for translation. Google's privacy policy applies to that data: https://policies.google.com/privacy

## Data Storage

- No data is collected or stored on external servers by us.
- No analytics, tracking, or telemetry is used.
- No cookies are set by the extension.
- No accounts or sign-ups are required.

## Changes to This Policy

If this policy is updated, changes will be reflected on this page with an updated date.
